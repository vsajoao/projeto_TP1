Detailed Description

Representa uma ordem de compra de papéis no sistema.

A ordem é composta por um identificador próprio, um código de negociação do papel, uma data, uma quantidade de papéis, o preço total da ordem, e o código da carteira à qual está associada. Todos os atributos são ntes, ou seja, não podem ser modificados após a criação da ordem.
